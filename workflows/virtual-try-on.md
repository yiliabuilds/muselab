# 工作流：真人模拟佩戴

入口："戴在手上 / 佩戴效果 / 上身图 / 试戴 / 放包上看看"。

## 前置：必须有可引用的设计

```bash
python3 scripts/muselab_state.py design-show --dir <proj> --id <design_id>
```

- 没有设计档案 → 先做设计（`jewelry-design.md`），不要凭一段描述就试戴。
- 有档案 → 用档案里的 `dimensions`（珠径/手围/链长）约束比例。这是避免"珠子像乒乓球"的唯一办法。
- 用户上传了自己的手腕/颈部/耳朵照片 → 作为 `reference_images` 一起给生成工具。

## 三种默认方案

| 方案 | image_type | 说法 |
|---|---|---|
| 日常自然光 | `try_on` | 窗边自然光，浅景深，生活场景（咖啡杯/衣料一角） |
| 近景细节 | `try_on` | 85–100mm 微距，可见皮肤纹理与珠面反射 |
| 商业广告 | `try_on` | 硬光+反光板，纯净背景或半身构图，成片感 |

用户只要一种就只做一种，不要凑数。

## 商品一致性的处理（核心难点）

生成式试戴**无法保证 100% 复刻**。诚实做法：

1. **优先**：把已定稿的商品图作为参考图（ImageGen `image1`，必要时 `image2/3` 补充角度），并把 `input_fidelity` 调高。
2. **提示词里锁死不可变项**（写在最前面，不是最后）：
   - 珠子数量与直径（例："12 颗 6mm 圆珠"）
   - 排列顺序（密—疏—密三段）
   - 金属件位置与颜色（"3 颗 3mm 925 银隔珠，位于第 4、5 颗之间"）
   - 闭合结构（"隐蔽式龙虾扣，位于手腕内侧"）
3. **出图后逐项核对**：珠数、排列、吊坠造型、金属色、比例、连接结构。任何一项不符 → 写进 `fidelity_notes`，并告诉用户可以重出，或直接改图。
4. **绝不**在回复里写"与原商品完全一致"。

## 人体真实性检查

- [ ] 五指、指关节数量正确（戒指/手链图常见 6 指）
- [ ] 首饰贴合部位有受力关系：手链下缘轻压皮肤，戒指有轻微陷肉
- [ ] 皮肤保留纹理与毛孔，无塑料磨皮
- [ ] 珠宝反光与环境光源方向一致
- [ ] 无悬浮、无穿模、无"粘"在皮肤上
- [ ] 比例正确：手链宽度不超过手腕宽度的 1/3；项链吊坠落在锁骨下 2–4cm

任何一条不过 → 明确说"这张图有 X 问题，不建议作为商业展示"，不要含糊带过。

## 合规

- 用户上传真人照片：仅用于本次合成，不外传、不建库；合成图默认不公开。
- 用他人肖像做商业图 → 需要授权；提醒一句即可，不要说教。
- 商业展示的 AI 试戴图 → 建议标注"AI 模拟效果，非实物佩戴实拍"（`copyright-and-safety.md`）。

## 降级

| 情况 | 交付 |
|---|---|
| 无参考图编辑能力 | 给三套完整试戴提示词（含锁定项）+ 尺寸比例说明，并说明"未生成图片" |
| 参考图上传但工具不支持多图输入 | 用最关键的一张（正面商品图）做 `image1`，其余用文字锁定 |
| 生成结果结构漂移严重 | 保留该图但标注"仅作氛围参考，结构不可作为验收依据"，并建议改用实拍 |
