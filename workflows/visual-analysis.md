# 工作流：视觉元素分析

入口：用户说"分析这张图 / 这图什么风格 / 有什么设计元素 / 能做出什么"。这是**通用能力**，不依赖首饰模块。

## 八个维度

逐个维度给**可观察证据**，禁止只写形容词。

| 维度 | 要写什么 | 反例 → 正例 |
|---|---|---|
| Color | 测得的色值 + 面积关系 | "蓝色" → "青蓝 #2E8B93 占 24%，与深蓝 #0F2B46 形成深浅层次" |
| Shape | 轮廓几何：曲率、连续性、重复单元 | "弧形" → "浪花是不规则短曲线，峰顶尖锐、两侧内收，重复周期约 3–5 个" |
| Texture | 表面性质：哑光/通透/颗粒/纤维 | "有质感" → "泡沫呈半透明乳白，边界破碎成小气孔；水面是高光连续的镜面" |
| Composition | 视觉重量分布、留白、视线路径 | "构图好看" → "主体偏下 1/3，上方 60% 为负空间，视线从左下向右上抬起" |
| Style | 可命名的风格坐标 | "高级感" → "极简自然主义，接近滨田庄司式的哑光生活感" |
| Mood | 情绪词 + 依据 | "清新" → "高明度（均 L 68）+ 低饱和（均 C 14）+ 冷色占比高 → 清爽、轻盈" |
| Symbol | 可识别的象征 | "海" → "潮汐的往复、贝壳的母性容器、盐的结晶" |
| Design Opportunity | 一句话一个可执行方向 | "把泡沫的破碎边缘做成不规则包边" |

Color/Mood 两维直接用 `scripts/color_extract.py --mode mood` 的实测输出，不要凭感觉写数值。

## 从元素到设计语言的转化表

这是分析的价值所在。每条都要"特征 → 转译手法 → 落到什么部件"：

| 视觉特征 | 转译手法 | 落到部件 |
|---|---|---|
| 不规则短曲线 | 异形珠/巴洛克珍珠的不对称轮廓 | 主石、吊坠外形 |
| 渐变色 | 同色系不同明度的珠子按明度递增排列 | 珠串序列 |
| 半透明乳白 | 透明与不透明材质混排，制造"透—实"节奏 | 泡沫白贝母 + 哑光白玛瑙 |
| 周期性节奏 | 疏—密—疏的排列结构 | 珠距、隔珠位置 |
| 硬边镜面高光 | 抛光银/黄铜镀金件作为视觉停顿 | 隔珠、扣件、包边 |

## 输出结构

```
一、看到什么（证据）
  颜色 / 形状 / 材质 / 构图 / 风格 / 情绪
二、意味什么（解读）
  象征、文化联想、常见误读（如"海洋=蓝白"其实原图主色是灰绿）
三、能做什么（设计机会，3–6 条）
  每条：特征 → 手法 → 部件 → 材质建议
四、不建议做什么
  例如：不要把渐变直接做成彩虹色珠子排列，会甜俗
```

## 规矩

- 只描述**图里真的有的东西**。看不出就写"无法判断"，不要补故事。
- 区分"观察"和"联想"：象征部分是解读，要标为解读。
- 用户的图如果是他人作品 → 只能提取视觉语言，不得复刻具体造型（见 `references/copyright-and-safety.md`）。
- 分析完不要自动往下做设计；用户没要求就停在分析，末尾问一句"要不要据此出设计方案"。
