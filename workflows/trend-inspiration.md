# 工作流：新闻灵感创作

入口："找这周适合做手串的新闻 / 热点变设计 / 新闻 → 小红书"。

## 第 1 步：联网检索（不可跳过）

必须用真实的搜索工具。没有搜索能力 → 直接说"无法联网"，请用户给链接或正文；**不得编造任何新闻**。

默认：近 7 天，3 条。检索式示例：

```
本周 动物保护 救助 新闻
近一周 非遗 传统工艺 展览
2026年11月 天文 流星雨 观测
本周 博物馆 新展 文物
近七天 青年 创业 设计 获奖
```

每条新闻必须落齐六项，缺一项就换一条：

| 字段 | 要求 |
|---|---|
| 标题 | 原文标题，不改写 |
| 日期 | 事件发生/报道日期，ISO 格式 |
| 来源 | 媒体名称 |
| 链接 | 可访问 URL（不得拼接捏造） |
| 事实摘要 | 3–5 句，只写发生的事 |
| 视觉关键词 | 3–6 个可用于设计的具象词 |

## 第 2 步：主题筛选

**优先**：自然生态、动物保护、天文与季节、非遗/艺术/博物馆、女性成长、青年创造、体育精神、科技便利、社区公益、公共文化。

**排除**：战争与政治冲突、灾难、犯罪、疾病、争议性负面事件、无法验证来源、不适宜商业化（丧葬、事故、诉讼）。

判断标准一句话：**这条新闻能不能被做成一件让人愿意戴着的、不带冒犯的东西。**

## 第 3 步：三款设计（结构必须不同）

每条新闻一个设计，三款在**结构 / 主色调 / 材质组合 / 视觉重点**上尽量不重叠。走 `workflows/jewelry-design.md` 的完整流程，逐款建档。

设计要能说清"新闻里的哪个具体细节变成了哪个部件"，例如"被救助的海龟背甲裂纹 → 拼接式异形贝母片"。

## 第 4 步：小红书文案

硬性规格：

- 标题 ≤ 18 个汉字
- 正文 160–260 个汉字
- 标签 ≤ 5 个
- 最后一行保留新闻来源链接

写作要求：
- 事实与创意分开：先一句新闻事实，再转到"我把它做成了什么"
- 口语、具体、少形容词堆砌；不写"绝美""高级感拉满"
- 不虚构公益合作、品牌联名、义卖捐赠
- 不宣称功效（招财、疗愈、能量、转运）
- 不消费苦难：不写"为 XX 祈福"式营销

模板：

```
标题：把一只海龟的背甲戴在手上

正文：
（1–2 句新闻事实 + 来源时间）
（2–4 句转译逻辑：为什么选这个细节、变成了什么结构）
（1–2 句佩戴场景/搭配）
（1 句克制的收尾，不喊口号）

#天然石手作 #海洋灵感 #小众设计

来源：<真实链接>
```

## 第 5 步：输出结构

```
本周三条（附来源表）
├─ 01 新闻标题｜日期｜来源｜链接
│   视觉关键词：...
│   设计：产品名 + 结构 + 主色 + 材质（可点开详案）
│   出图：已生成 <路径> / 未生成 + 提示词
│   文案：（按规格）
├─ 02 ...
└─ 03 ...
```

## 红线

- 不编新闻、不编链接、不编日期、不编"官方合作"。
- 不用灾难/伤亡/疾病画面做设计卖点。
- 涉及真实人物（尤其未成年人）→ 不做肖像化设计，不写其姓名。
- 新闻事实部分必须能被来源链接验证；创意延伸部分要能被读者识别为创意。
