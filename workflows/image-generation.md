# 工作流：图像生成与提示词

入口：需要把设计变成图（商品图/效果图/氛围图），或用户说"出图 / 生成看看"。

## 第 0 步：先定路线

**不要跳这一步直接写提示词。** 三条路线的输入与验收完全不同，见 `workflows/generation-modes.md`：

| 情况 | 路线 |
|---|---|
| 设计还是 `draft`，实物不存在，只想看气质 | **B. Creative Generation**（文生图，十段式） |
| 有实物照片，拍得差，只想要好看的展示图 | **C. Reference-Based Generation**（参考图 + 编辑，只能标 AI 模拟） |
| 有实物照片，只要换背景/底色，且必须"就是这件商品" | **A. Product Compositing**（`cutout.py` + `compose.py --keep-frame`，不调生成模型） |

拿不准就问一句："这张图是给内部看想法，还是要当商品图用？"——这一句决定了后面全部参数。

妆容出图另走 `workflows/makeup-design.md` 的第 7 步（六段式提示词）；妆容没有 A 路线。

## 先决条件：调用成本

MuseLab 的图像生成走宿主的图像生成工具（如 `ImageGen`）。**每张图大约消耗 5–10 点额度，调用前必须先告诉用户**："接下来会生成 N 张图，每张约 5–10 点额度，是否继续？"

用户没明确同意 → 只给提示词，不调用。**一次授权只覆盖一次调用**；重试、加图、换版本都要重新确认。

## 十段式提示词（缺一段就不完整）

1. **主体**：一件 6mm 海蓝宝三段式手链（明确品类+结构）
2. **结构**：12 颗 6mm 圆珠分三段，朱 3 颗 3mm 银隔珠分隔，另一端接 4cm O 字链与龙虾扣
3. **材质与颜色**：半透海蓝宝（HEX #2E8B93 至 #7FB3B8 渐变）、925 银哑光、象牙白珍珠
4. **背景**：纯白无缝背景 / 米白亚麻布 / 浅灰渐变
5. **角度**：正俯 90° 平铺 / 45° 侧俯，主体占画面 70%
6. **光线**：柔光箱 45°主光 + 右侧反光板补光，柔和投影，无硬阴影
7. **镜头与构图**：100mm 微距，f/8，中心构图，留白均匀
8. **比例**：1:1（商品图）/ 4:5（社媒）/ 16:9（横幅）
9. **真实感**：商业产品摄影，真实材质反射，可见珠面细微纹理，无塑料感
10. **负面词**：见下

中文提示词是首选（宿主模型对中文珠宝术语理解稳定）；需要英文时保持同样结构。

### 写结构的三种句式（按可靠性排序）

实测结论：模型对"关系"的理解远好于对"参数"的理解。

1. **分层关系句**（最可靠）："圆环由链与玉髓串联成一条连续的线；珍珠从中央小环**向下垂挂**，不与珠子串在同一条线上。"——把每段的从属关系说清，模型不会把吊坠画成串珠。
2. **单向顺序句**："从左起：扣 → 环 → 链 7.3cm → 环 → 隔珠 → 玉髓 → 中央环 → 镜像 → 延长链。"——适合线性结构，避免"两次提到同一段"被理解成两段。
3. **数量锁定句**："珍珠 1 颗、青珠 2 颗左右各 1、隔珠 2 颗；除此不得增加任何珠子。"——单独成句，比夹在描述里有效。

**无效写法**："银线半包 3/4 周并保持不遮住珠面"——模型会画成金属笼。要写成否定式："金属只出现在珍珠顶端，**不得缠绕珠体、不得包边、不得出现镶爪**。"

## 负面词库（按需组合）

```
多余珠子，珠数错误，悬浮配件，断裂的链子，错位的金属件，水印，文字，logo，
品牌标识，塑料质感，过度磨皮，AI 感，畸变，多余手指，模糊，噪点，
夸张大珠，悬浮阴影，双光源冲突，镜面倒影错误
```

结构类负面词要**针对本款写**，通用词库抓不住具体误读方向。例：吊坠款加"珍珠串在链条上、与圆珠同轴穿连、主石嵌在环线中间、金属包边、镶爪、金属笼"。

## 比例与尺寸

| 用途 | aspect_ratio | size 建议 |
|---|---|---|
| 电商主图 | 1:1 | 1024x1024 / 1536x1536 |
| 社媒/小红书 | 4:5 或 3:4 | 1024x1536 |
| 详情页横幅 | 16:9 | 1536x1024 |
| 佩戴特写 | 4:5 | 1024x1536 |

## 执行与登记

```bash
# 1) 登记任务（generation_mode 必填：concept | product_fidelity）
python3 scripts/muselab_state.py task-add --dir <proj> --design-id <id> --file task.json
# 2) 调工具（工具为宿主提供，见 SKILL.md 的能力探测）
# 3) 成功
python3 scripts/muselab_state.py task-done --dir <proj> --task-id img_x --path <真实路径> \
  --tool ImageGen --fidelity-notes "第 2 颗珠位置偏移，吊坠形状略简"
# 3') 失败或无工具
python3 scripts/muselab_state.py task-fail --dir <proj> --task-id img_x --reason "无图像生成工具" --no-tool
```

有参考图时务必传（`image1`，必要时 `image2/3`），并把 `input_fidelity` 调高；纯文字生成几乎必然改结构。

## 出图后：跑门禁，不要只靠眼看

```bash
python3 scripts/fidelity_check.py --config gate.json --json gate_result.json \
    --overlay qa_overlay.png --strict
```

`gate.json` 只需写四件事：图片路径、目标背景色、每种材质的期望色与采样点、必须可见的配件 ROI。全字段见 `references/api_reference.md`。

门禁只判**可测项**（背景纯度、去光照后的色差、ROI 锐度、ROI 前景占比）。它不会告诉你"这是不是龙虾扣"，也不会数珠子——那些必须视觉模型或人工，报告里会分栏列出。

## 质量门禁

### 可代码判定（`fidelity_check.py`）

- [ ] 背景：`pass_seamless`（无缝纯色）；`lit_backdrop`（有打光渐变）与 `off_spec`（色偏超容差）都算不过
- [ ] 材质：无 `material_mismatch`（色相漂移或饱和度塌陷）
- [ ] 配件：必需 ROI 无 `absent_at_roi`
- [ ] 清晰度：必需配件 ROI 不是 `unverifiable_blur`

### 必须视觉/人工判定

- [ ] 结构：珠数、分段、主石固定方式与档案一致
- [ ] 配件身份：扣是扣、环是环，没有被熔成一坨
- [ ] 物理：无悬浮、无穿模、无凭空多出的配件
- [ ] 文字：画面内无乱码文字；工具水印是否已处理
- [ ] 比例：主体未被拉伸，链条粗细合理

### 颜色判定：不要用"ΔE < 8"一刀切

见 `references/product-consistency.md`。简版：

| 类型 | 判什么 | 容差 |
|---|---|---|
| 设计色（纯色块、印刷色） | 直接比 δE | ≤ 4 |
| 材质本色（宝石、珍珠） | **先扣掉画面光照色偏**，再看色相与饱和度总量 | 色相 ±10–14°，饱和度 −35%~+25%，明度残差 ±8~10 L* |
| 金属 | 只看色相（银中性 / 金 ≈ 85°） | 色相 ±10°；明度饱和由高光决定，不判 |

明度偏但色相对 → `tone_shift`，是打光/曝光问题，后期可修，**不要说成"材质不对"**。

任一硬门禁不过 → 改提示词重出，或如实标注问题并说明可修正性。**不要交付一张结构错误的图并说"已完成"。**

## Mode B（无工具）

交付：
1. 完整提示词（十段式）+ 结构关系句
2. 负面词（含本款专属误读方向）
3. 比例与尺寸
4. 参考图建议（用哪张、为什么、`input_fidelity` 设多少）
5. 出图后复查清单（上面两栏）
6. 一句话说明：**"当前环境没有可用的图像生成工具，以上是可直接粘贴使用的提示词，图片尚未生成。"**
