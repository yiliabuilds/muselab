# 工作流：吸色与配色

入口：用户说"提取颜色 / 吸色 / 配色 / 色板 / 这个色调 / 什么颜色"。

## 第 1 步：真实测量

```bash
python3 scripts/color_extract.py <图片> --mode mood --max-colors 6 \
  --swatch <workspace>/exports/<name>_palette.png --json <name>_colors.json
```

- `--mode color`：只要代表性颜色。
- `--mode mood`：额外给明度、饱和度、冷暖、对比、情绪词——用户说"氛围/感觉/调性"时用它。
- 只关注主体（已抠图）时加 `--mask <cutout>.png`，只在主体范围内取色。
- 输出 `extraction_method = pixel_kmeans_lab` 且 `is_measured = true` → 这是**实测值**，可以写"测得"。

没有 numpy/Pillow 时用 `--no-pixels`，输出会自带 `extraction_method = visual_estimate`，此时必须写"近似估计"。

## 第 2 步：把色板翻成设计语言

不要只报色值。每个色要回答四件事：

| 字段 | 例（海滩） |
|---|---|
| 角色 | 主色 / 辅助 / 点缀 |
| 面积占比 | `0.32` → 说明它是大面积底色 |
| 设计用法 | 主石 / 隔珠 / 金属件 / 编绳 |
| 材质映射 | 深海蓝 → 青金石或海蓝宝；贝壳白 → 淡水珍珠；沙滩米 → 贝母 |

材质映射要遵守 `references/jewelry-design-rules.md`：色只是方向，最终要落到**真实存在的材质**上，并且不同材质的色泽差异要写清楚（例如"青金石偏哑光带金星，海蓝宝偏透亮"）。

## 第 3 步：关系分析

`color_extract.py` 会返回 `relationships.highest_contrast_pairs`（含 ΔE 与 WCAG 对比度）与 `palette_span_delta_e`：

- ΔE < 10 的两个色放在一起会「糊」→ 不要做成相邻珠子，中间插隔珠或金属件。
- ΔE > 45 → 天然适合做主次对比（大面积主色 + 单颗点缀）。
- WCAG 对比 < 2.0 → 只适合做质感层次，不适合做视觉重点（用于详情页文字配色时更要注意）。

## 第 4 步：按应用领域给建议

同一色板，三个领域三种落法（用户没说领域时给首饰，因为这是主场景）：

- **首饰**：主色 → 主珠材质；辅助 → 过渡珠/编绳；点缀 → 单颗异形珠或金属件。
- **妆容**（模块未实现，只给通用建议）：底色/眼影/唇色的角色分配与饱和梯度。
- **穿搭**：70/25/5 面积法则，主色为最大件。


## 陷阱

- 截图带 UI、水印、大面积白边 → 先 `--crop` 再取色，否则白色会吃掉主色占比。
- 渐变图 → k-means 会把渐变切成几段，属正常；要说明"这是分段代表色，不是单一色"。
- 照片有强色偏（阴天/暖光）→ 报实测值的同时提示"原图色偏会影响结果"，不要自己"校正"后当成实测值。
