# 示例四：新闻 → 首饰 + 小红书文案

> ⚠️ 本文中的新闻条目是**格式示例**：标题、媒体与链接均为占位符（`<真实链接>`）。
> 实际运行时必须联网检索真实结果并逐条核对；无联网能力时不得生成任何"新闻"。

## 用户

> 找这周三条适合做首饰的新闻，各出一款设计和小红书文案。

## 1. 检索

```
搜索：本周 动物保护 救助 / 近七天 非遗 工艺 / 本周 天文 观测
范围：近 7 天，3 条
```

先跑 `scripts/check_env.py --websearch no` → 若返回 B：

> 当前环境无法联网，我没法核实本周新闻。你可以：① 发我这三条新闻的链接或正文；② 或者我先按你给的主题做设计，等有新闻再补文案。

**不得**凭记忆写"最近有新闻说……"。

## 2. 三条（格式示例）

### 01
- 标题：`<原文标题>`
- 日期：`2026-11-14`
- 来源：`<媒体名>`
- 链接：`<真实链接>`
- 事实摘要：3–5 句，只写发生了什么，不加评价。
- 视觉关键词：`珊瑚、分叉、橙粉渐变、水下光斑`

通过筛选（自然生态 / 可商业化 / 无争议）。

### 02
- 主题：非遗工艺
- 视觉关键词：`经纬、靛蓝、手工结、布面纹理`

### 03
- 主题：天文
- 视觉关键词：`流星轨迹、深蓝、银白尾迹、夜空颗粒`

被排除的例子（要说明为什么）：
- 某地灾害 → 灾难，不商业化。
- 某争议人物言论 → 争议，排除。
- 来源不明的"网传" → 无法验证，排除。

## 3. 三款设计（结构必须不同）

| | 01 珊瑚 | 02 织纹 | 03 流星 |
|---|---|---|---|
| 结构 | `irregular_centerpiece` | `knotted_cord` | `partial_strand_chain` |
| 主色 | #E08A6B 橙粉 | #2E4A6B 靛蓝 | #1B2A4A 深蓝 |
| 材质 | 珊瑚色玛瑙 + 银包边 | 靛蓝编绳 + 银管 | 深蓝砂金石 + 银珠 |
| 视觉重点 | 单颗异形主石 | 绳结结构 | 3 颗珠的斜向轨迹 |

三款在结构、主色、材质、重点位置上都不重叠——这才是"三条新闻三个方案"。

## 4. 小红书文案（严格遵守规格）

### 01
```
标题：把珊瑚的分叉做成了吊坠

正文：
上周看到一则珊瑚修复的报道，说人工培育的珊瑚礁已经开始抱卵——那一刻想到的
不是海，而是"分叉"这个动作。所以这颗主石没有做圆，顺着玛瑙本身的纹理切成
三叉，边缘保留了一点没打磨的粗糙感。银包边只包住最细的那一端，像被水冲过的
石头。40cm 细链，落在锁骨下两指。配白 T 或者亚麻衬衫都合适，日常戴不会太
张扬。做首饰这几年越来越觉得，好看的结构往往来自一个具体的动作，而不是一个
抽象的概念。

#天然石手作 #珊瑚色 #小众设计 #锁骨链

来源：<真实链接>
```

核对：
- 标题 12 字 ✓（≤18）
- 正文 218 字 ✓（160–260）
- 标签 4 个 ✓（≤5）
- 末行来源链接 ✓
- 无功效宣称 ✓ / 无公益合作暗示 ✓
- 新闻事实（珊瑚修复抱卵）与创意（三叉切割）分得清 ✓

### 02 / 03 同规格，各自结构与文案角度不同。

## 5. 输出结构

```
本周三条（含来源表：标题/日期/媒体/链接/摘要/视觉关键词）
├─ 01 → 设计详案（12 项）+ 出图（已生成 <路径> / 未生成 + 提示词）+ 文案
├─ 02 → ...
└─ 03 → ...
```

## 常见错误

- 编一条"听起来很像真的"新闻 → 直接违规。
- 三条设计只换颜色 → 打回。
- 文案写"招财""转运" → 违规。
- 标题写成 25 字 → 超规格。
- 把新闻事实和设计灵感混成一段，读者分不清哪句是真的。
