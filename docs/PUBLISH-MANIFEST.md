## 6. Repository state, and what is still open

The tree is a git repository on branch `main` with all 86 files staged. The first commit
(`Initial release: MuseLab v1.3.1`) has **not** been created: no author identity is configured on
the build machine, and inventing one would put a false name in a public history. **No remote, no
tag, nothing published.**

1. Staged file count: **86** — the same number as `find . -type f | wc -l`. If those two numbers
   ever diverge, something unmatched by `.gitignore` crept in.
2. Still open: a `SECURITY.md` with a reporting address (the address has to come from the
   maintainer — it cannot be invented), and a `CITATION.cff` if desired.
3. Size decision: the tree is ~11 MB, of which `demos/images` is 3.2 MB and `tests/fixtures` is
   7.3 MB. Shrinking the fixtures would break pixel-coordinate assertions — they stay.
4. Repository name and one-line description are fixed as `muselab` / *A modular AI visual workflow
   that transforms visual references into structured creative designs with measurable validation.*
   Both READMEs already carry that positioning.
