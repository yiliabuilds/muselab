# 商业摄影规范（提示词落地版）

## 十段式

主体 → 结构 → 材质与颜色 → 背景 → 角度 → 光线 → 镜头与构图 → 比例 → 真实感 → 负面词。

少一段，模型就会自己编。

## 镜头与景深

| 用途 | 焦段 | 光圈 | 效果 |
|---|---|---|---|
| 商品主图（平铺） | 90–100mm 微距 | f/8–f/11 | 全清晰，边缘锐利 |
| 商品主图（立体） | 85–100mm | f/5.6–f/8 | 主体清晰，背景轻虚 |
| 佩戴特写 | 85–100mm | f/2.8–f/4 | 皮肤纹理在，背景化开 |
| 氛围场景 | 50mm | f/1.8–f/2.8 | 生活感，主体仍可辨 |
| 系列合影 | 50–70mm | f/8 | 透视自然，不挤压 |

不要写"大光圈唯美虚化"——写具体 f 值。

**但 f 值写进提示词不等于真的全实焦。** Eddy v5 实测：提示词写 f/9 100mm，生成图的远侧链节锐度只有画面参考值的 11–17%，龙虾扣所在区域完全无法核对。所以景深是否达标必须**测**，不能靠提示词承诺：

```bash
# 用配件 ROI 的 Laplacian 方差 vs 全图 p90 参考值判断
python3 scripts/fidelity_check.py --config gate.json      # 看 accessories[].status
```

| 比值 | 判定 | 处置 |
|---|---|---|
| ≥ 0.25 | `sharp_enough_to_verify` | 可交视觉复核 |
| < 0.25 | `unverifiable_blur` | 该配件无法验收，换角度/增大景深或分区域拍 |

Product Fidelity Mode 下"主图全实焦"是**硬要求**；Concept Mode 允许远侧柔化，但主石与主扣件必须在焦内。

## 光线

- **柔光箱 45° 主光 + 对侧反光板**：最稳的商品光，珠面有高光但不死白。
- **顶部柔光 + 白底透光**：适合透明石与浅色珠，减少投影。
- **单侧硬光 + 黑卡**：强调金属线条与异形轮廓，适合设计感强的款。
- 禁用：双主光对打（出现双阴影）、彩色环境光（改商品色）、直闪（死白高光）。
- 金属与珍珠必须写"高光柔和且方向一致"。

## 角度

- 正俯 90°：平铺、结构展示（能看清排列）。
- 45° 侧俯：立体感、商业主图最常用。
- 平视：佩戴感、长度比例。
- 主体占画面 65–75%，四周留白均匀；不要顶边。

## 背景

纯白无缝（#FFFFFF）/ 浅灰渐变（#F5F5F5→#E8E8E8）/ 米白亚麻 / 深灰石板 / 湿润水面。
背景只服务主体，不得有抢眼的图案、文字、其他产品。

### "无缝纯色"要能测，不能只是写

| 指标 | 合格 | 含义 |
|---|---|---|
| 边缘 8 点平均 ΔE | ≤ 6（按目标色） | 颜色大致对得住 |
| 边缘 8 点 ΔE 极差 | ≤ 3 | 没有明显明暗渐变 |
| 单点 48×48 内 L* 标准差 | ≤ 3 | 没有布纹/纹理 |

任一超标即不是"无缝纯色"：色相接近但有渐变 → `lit_backdrop`（打光布景）；ΔE 超标 → `off_spec`。Eddy v5 实测：目标 `#F2EFE9`，上部 `#C9B3A0`（ΔE 22.8）、下部 `#DACABE`（ΔE 13.6）、极差 14.4 → 是打了光的米色背景布，不是无缝纯色。

### 主体与背景的分离度

浅色商品 + 浅色背景是商品图的高频翻车点。若采样区与背景 ΔE < 10 且区内亮度范围 < 10，则该区域**无法可靠判色**（`inconclusive_low_separation`）。

处置：加轮廓光、换中灰/白色分级背景、或在商品后方垫一片浅灰卡纸；纯靠后期拉背景救不回来（边缘光晕会露）。

## 真实感关键词（有效）

- 中文：真实材质反射、可见珠面细微纹理与冰裂、金属有细微划痕、柔和接触阴影、无塑料感、商业产品摄影、中画幅质感。
- 英文：photorealistic product photography, visible stone inclusions, soft contact shadow, subtle metal micro-scratches, no plastic sheen, medium format look.

## 无效词（别用）

"高级感""唯美""大气""质感爆棚""ins 风""绝美" —— 模型无法解析，只会加滤镜感。

## 负面词

```
多余珠子，珠数错误，悬浮配件，断裂链条，错位金属件，水印，文字，logo，品牌标识，
塑料质感，过度磨皮，AI 感，畸变，多余手指，模糊，噪点，夸张大珠，双光源冲突，
镜面倒影错误，裁切主体
```

## 出图后验收

1. 结构对不对（珠数/分段/五金位置）
2. 材质像不像（金属、透明石、珍珠各自的反射逻辑）
3. 物理合不合理（有没有悬空、穿模、投影缺失）
4. 有没有乱码文字 / 工具水印
5. 比例有没有被拉伸
6. 背景纯度与主体分离度是否达标（上表）
7. 配件 ROI 是否锐到可核对
8. 颜色按三层判（设计色 / 材质本色 / 光照），不是"ΔE < 8"

前 3 条不过 → 重出，不要交付。6–8 条用 `scripts/fidelity_check.py` 出机器结论，再叠加视觉复核。
