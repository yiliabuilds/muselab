# 色彩理论（设计可用版）

## 用 Lab 而不是 RGB 做判断

RGB 的数值距离和人的感觉不一致。`scripts/color_extract.py` 在 CIELAB 里聚类，原因：

- **L\***：明度 0–100。L 差 10 以上才有明显明暗区分。
- **a\*/b\***：色度方向。`C = √(a²+b²)` 是饱和度，`h = atan2(b,a)` 是色相角。
- **ΔE（CIE76）**：`ΔE ≈ 2.3` 是普通人能察觉的阈值。设计上可用的经验值：

| ΔE | 视觉关系 | 设计用法 |
|---|---|---|
| < 5 | 几乎同色 | 只做质感区分（哑光/抛光） |
| 5–10 | 同族微差 | 相邻会"糊"，中间必须插隔珠/金属 |
| 10–25 | 同族深浅 | 渐变珠串、层次过渡 |
| 25–45 | 明确对比 | 主色 + 辅助色 |
| > 45 | 强对比 | 主色 + 单颗点缀 |

WCAG 对比度（`color_extract.py` 里也有）在 2.0 以下 = 只适合做质感层次，不适合做视觉重点。

## 面积法则

- **60-30-10**：主色 60%（大面积材质）、辅助 30%（结构过渡）、点缀 10%（金属/单颗异形珠）。
- 首饰的"10%"往往只有 1–3 颗珠或 2–3 个五金件——这正是精致感的来源。
- 反过来：点缀超过 20% 会变"杂"，低于 3% 会被忽略。

## 冷暖与情绪

| 色相（Lab h） | 冷/暖 | 常见情绪 | 首饰材质对应 |
|---|---|---|---|
| 0–45 洋红/红 | 暖 | 热烈、张扬、节庆 | 南红、朱砂、红玛瑙、玫瑰金 |
| 45–75 橙 | 暖 | 温润、食欲、日常 | 蜜蜡、虎眼石、黄铜 |
| 75–110 黄 | 暖 | 明快、贵气 | 黄水晶、金色配件 |
| 110–175 绿 | 中性偏冷 | 自然、平静、疗愈感 | 孔雀石、绿松石、和田玉 |
| 175–250 青 | 冷 | 清爽、通透、理性 | 海蓝宝、托帕石、青金石（偏深） |
| 250–320 蓝 | 冷 | 沉静、克制、高级 | 蓝宝石、青金石、蓝纹玛瑙 |
| 320–360 紫 | 冷暖交界 | 神秘、女性化 | 紫水晶、舒俱来 |

低饱和（C < 12）+ 高明度（L > 75）= 我们说的"清冷感"；高饱和 + 低明度 = "浓郁/复古"。

## 肤色适配（谨慎使用，不做绝对判断）

- 暖皮（偏黄/蜜色）：暖色与金色更协调；冷色需降低饱和度。
- 冷皮（偏粉/青白）：银、冷蓝、冷粉更干净；暖金易显黄。
- 中性皮：几乎都能戴，适合做多色系列。
- 不确定时：选中间明度（L 45–65）+ 中等饱和（C 15–30），最不容易出错。

不要写"这个颜色显白/显黑"这类绝对结论，改为"与暖皮更协调"。

## 常见配色错误

1. **彩虹渐变**：把所有提取色按色相排成一条珠子 → 甜俗。正确做法是取 2–3 个同族色做明度渐变。
2. **同明度撞色**：两个不同色相但 L 相同（如 #2E8B93 与 #9CB89A 都偏中调）相邻，视觉上会"打架又糊"。
3. **主色不占主导**：5 个颜色各 20%，没有主角。
4. **金属色当主色**：金色/银色是"标点"，不是"正文"。
5. **忽略材质本色**：设计写 #7A5C43 的"棕"，但选的是虎眼石（有色带）——色值只能近似，必须说明材质会带来色差。

## 交付话术

- 实测：「测得主色 #2E8B93（采样 12,480 px，占 24%）」
- 推测：「目测接近 #2E8B93，未做像素测量，属近似值」
- 材质色差：「珠子实物的色相会随光线与材质纹理浮动，HEX 是设计基准，不是验货标准」
