# 商品一致性（多图 / 试戴 / 保真出图）

生成模型不理解"同一件东西"。它理解的是"看起来像"。所以一致性靠约束，不靠描述。

## 两种模式的一致性目标不同

| | Concept Mode | Product Fidelity Mode |
|---|---|---|
| 比什么 | 设计意图 | 真实商品 |
| 参考图 | 可选（只借风格） | **必须有**，`image1` 起步 |
| 颜色判据 | 设计色系对不对 | 材质本色对不对，光照色差不算错 |
| 允许的差异 | 明显（可换构图、换光） | 极小（结构/配件/金属色不可漂移） |

模式定义见 `workflows/generation-modes.md`。

## 会漂移的东西（按发生频率）

1. 珠子数量（最常见，+1 / -2）
2. 珠子排列顺序（分段被打乱）
3. 吊坠造型（变简单/变复杂/变圆）
4. 金属件颜色（银变金、金变玫瑰金）
5. 闭合结构（龙虾扣变磁扣、延长链消失）
6. 比例（珠子变大、链变粗）
7. 材质（透明石变不透明、珍珠变玻璃珠）
8. **吊坠与链的关系**（该垂挂的被画成串珠，或该串的变成吊坠）——Eddy v5 实测：这是"文字描述顺序"造成的，不是模型随机

## 三个约束手段（按有效性排序）

1. **参考图**：把已定稿商品图作为 `image1`（必要时 `image2` 补侧面/细节），提高 `input_fidelity`。这是唯一真正有效的办法。
2. **结构化档案**：把珠数、序列、五金位置写进 JSON（`schemas/design-spec.schema.json`），每次出图都从档案读，不要从记忆里写。
3. **提示词锁定段**：把不可变项放句首，逐条陈述：
   - "12 颗 6mm 圆珠，分 3-4-5 三段"
   - "3 颗 3mm 银隔珠，分别位于第 4、9、13 颗之后"
   - "末端为 4cm O 字链 + 龙虾扣"
   - "不得改变珠数、排列、金属颜色与吊坠形状"

描述性形容词（"精致的""高级的"）对一致性毫无作用。**关系句 > 顺序句 > 数量句 > 形容词。**

## 颜色一致性：三层色差，不要一刀切

**规则源头**：`#F2EFE9` 的背景在实测里变成了 `#C9B3A0`（ΔE 22.8）；`#128D97` 的青珠变成了 `#166B6F`（ΔE 14）——但后者的**色相只偏了 2.8°**，偏的是明度。用 ΔE 单一阈值会把"打光偏暗"判成"拿错石头"，从而做出错误的补救动作。

所以判色必须分三层：

| 层 | 是什么 | 怎么判 | 容差（默认） |
|---|---|---|---|
| **设计色** | 纯色块、印刷色、涂装色（flat fill） | 直接比 δE(ab) | ≤ 4，超了就是错色 |
| **材质本色** | 宝石、珍珠、玉髓等天然/半天然材料 | **先扣掉画面光照色偏**，再看色相角与饱和度总量；明度单列 | 色相 ±10°（珍珠 ±14°）、饱和度比值 −35%~+25%、明度残差 ±8~10 L* |
| **摄影光照** | 整体曝光、色温、阴影 | 用已知背景色反推：`cast = 实测背景 Lab − 目标背景 Lab` | 这部分**不算错误**，只记录 |

### 光照色偏怎么估

前提：背景的目标色是**先验已知**的（比如"无缝 `#F2EFE9`"）。此时背景实测色与目标色的 Lab 差，就是这张图的光照 + 白平衡偏移。

```
cast_a = bg_measured.a* − bg_expected.a*
cast_b = bg_measured.b* − bg_expected.b*
cast_L = bg_measured.L* − bg_expected.L*      # 整体曝光
```

比较材质色时，把 `cast_a/cast_b` 从实测值里扣掉；把 `cast_L` 从明度差里扣掉。剩下的残差才是"材质本身对不对"。

**这个补偿只在背景目标色已知时有效。** 背景是刻意设计的米色亚麻布、深灰石板时，不能反推光照，只能退化成"不做色彩判定，交人工"。

### 判定分支

```
扣掉 cast 之后：
  色相漂移 > 2×容差 或 饱和度塌陷 → material_mismatch（材质/染色不对）
  色相、饱和度都在容差内，但明度残差超了 → tone_shift（打光/曝光问题，后期可修）
  三者都在容差内 → pass_within_lighting（哪怕是 ΔE 20 也算过）
  高光占比过高（L p95−p5 > 55）→ inconclusive_specular（不判，交人工）
  采样盘与背景 ΔE < 10 且平坦 → inconclusive_low_separation（主体与背景同色，判色不可靠）
```

`tone_shift` 与 `material_mismatch` 的区分很重要：前者调色能救，后者必须换材质或重做。混为一谈会导致错误的补救。

## 配件可见性（复杂首饰必查）

结构信息都在小件上，小件最容易消失。

| 配件 | 典型漂移 | 代码可查 | 必须视觉/人工 |
|---|---|---|---|
| 龙虾扣 | 变磁扣、被省略 | 该 ROI 有无前景、是否虚化 | 形态对不对、爪口是否可动 |
| 延长链 | 整段消失、变成第二条链 | 同上 | 长度比例、末端尾珠 |
| 连接环 | 熔接成一坨、开口未闭 | 同上 | 环与环是否分明 |
| 吊坠固定结构 | 变包边/镶爪/金属笼、胶痕外露 | ROI 前景与锐度 | 金属是否缠绕珠体 |

判定口径：
- `absent_at_roi` → 声明的区域内几乎没有前景 → 配件缺失或移位（硬门禁不过）
- `unverifiable_blur` → 有东西但虚到看不清 → **不能算通过，只能算"无法验收"**
- `ready_for_vision_review` → 有且清晰 → 仍需视觉确认真身

**"这块区域有个东西且是清晰的"不等于"这是个龙虾扣"。**

## 验收清单（每张图逐项）

- [ ] 珠数与档案一致（允许 ±1，且必须记录）
- [ ] 分段/排列一致
- [ ] 吊坠形状与孔位一致；垂挂/串接关系与 Spec 一致
- [ ] 金属色一致（色相判，不判明度）
- [ ] 闭合结构存在、位置合理、且**在画面里看得见**
- [ ] 比例一致（珠径 / 链宽 / 整体长度）
- [ ] 无新增元素（多出的珠、吊牌、刻字）
- [ ] 背景纯度与主体/背景分离度

## 写进 fidelity_notes 的话术

不要写"基本一致"。写事实 + 归类：

> 珠数一致（珍珠 1、青珠 2、隔珠 2）；吊坠为垂挂关系，与 v5 一致。青珠色相漂移 2.8°，明度低 9 L*（已扣曝光）→ tone_shift，调色可修。背景实测 #C9B3A0 vs 目标 #F2EFE9，ΔE 22.8，非无缝纯色 → 不可作主图。扣件区域锐度仅为参考值 17%，无法核对是否存在龙虾扣。

## 分类：精确合成 vs 生成模拟 vs 概念稿

| 类型 | 手段 | 能承诺什么 |
|---|---|---|
| 精确合成 | 真实抠图 + alpha 合成（`cutout.py` + `compose.py`） | 像素级保留原商品，只换背景 |
| 生成模拟（保真模式） | 参考图 + 图生图 + 门禁 | 结构与配件可控，颜色需判，非像素级 |
| 概念稿（概念模式） | 文生图 | 氛围与风格，结构可能变化 |

**绝不把后两类说成第一类。** 用户要"这个商品放到手腕上"，只有第一类能保证商品不变；若只有生成能力，必须提前说明。

## 商业使用

AI 生成/模拟的佩戴图用于商品页、投放素材时：

- 标注"AI 模拟效果，非实物佩戴实拍"（中国《互联网广告管理办法》对虚假广告有约束，AI 合成不得让消费者误认为实拍）。
- 不得用 AI 图掩盖真实商品的瑕疵或尺寸。
- 用户上传他人肖像做合成 → 需肖像权授权。
- 工具自带水印必须裁掉或注明，不能当作品交付。
