# 首饰设计规则（可制作性）

设计的第一验收标准不是好看，是**能做出来、能戴住、不散架**。

## 珠子尺寸与重量

| 直径 | 单颗重（天然石/玻璃） | 用途 |
|---|---|---|
| 4mm | ≈0.15g | 细串、耳饰、隔珠带 |
| 5mm | ≈0.3g | 淡水珍珠常规、叠戴细串 |
| 6mm | ≈0.5–0.7g | **手串主力尺寸** |
| 7mm | ≈0.8–1.0g | 男款/中性手串 |
| 8mm | ≈1.2–1.5g | 手串上限常规值 |
| 10mm | ≈2.0–2.5g | 单圈偏重，需控制颗数 |
| 12mm+ | ≈3.0g+ | **只能单颗或 2–3 颗作视觉重点** |

手围 16cm 用 6mm 珠约需 22–23 颗（含隔珠）。8mm 约 17–18 颗。**先算珠数，再写设计**，不要写"若干颗"。

## 佩戴负重

- 手串：10–20g 舒适，>30g 会明显坠手。
- 项链：20–40g 常规；>50g 需加宽链或双链分担。
- 耳饰：单只 ≤8g（耳垂舒适上限），>10g 必须做耳夹加托或改短。

## 闭合结构（必须有）

| 结构 | 规格 | 适合 |
|---|---|---|
| 弹力线 | 0.7–0.8mm 透明弹力线，双股穿 2 圈，打结藏入珠孔 | 手串，无金属件更轻 |
| 钢丝线 + 收尾扣 | 0.5–0.6mm 钢丝线 + 2mm 压珠 + 收尾扣 | 需要造型稳定的串珠 |
| 龙虾扣 | 10–12mm，配 3–5cm 延长链 | 手链/项链通用 |
| OT 扣 | 金属环 + T 形杆 | 简约、可调长度 |
| S 钩 | 需配重力足够的坠子 | 复古、项链 |
| 磁扣 | 不推荐用于 >20g 的串 | 老人/儿童易用 |

延长链 3–5cm 是标配：让 15–18cm 手围都能戴。

## 五金与连接件（真实名称）

隔珠（2–3mm 光面/条纹）、包金珠、花托（托住珠孔遮线）、线圈（收线装饰）、九字针（做吊坠连接）、T 针、耳钩/耳夹、挂环（开口圈）、龙虾扣、延长链、收尾扣、压珠。

**连接规则：**
- 吊坠必须能指认孔位：单孔垂直穿线 / 双孔横穿 / 包边镶 + 顶部挂环。写"用胶粘"要标为不推荐。
- 金属件与天然石之间加隔珠或包金珠，避免硬碰硬磨损。
- 九字针两端圈口必须闭合（否则会滑脱），开口圈要"开—穿—合"到位。
- 珠孔小于线径会穿不过：0.8mm 孔配 0.6mm 线是安全组合。

## 材质质感对照（写设计时别都写"光泽"）

| 材质 | 真实观感 | 常见误写 |
|---|---|---|
| 925 银 | 冷白，会氧化发暗，抛光后镜面 | "亮银色金属" |
| 黄铜镀金 | 暖黄，边角易磨出底色 | "金色，永不褪色" |
| 14K 包金 | 暖金，耐磨，比镀金稳定 | 与镀金混为一谈 |
| 淡水珍珠 | 柔光晕彩，形状常不完美 | "圆润完美" |
| 巴洛克珍珠 | 不规则、有机曲面 | "异形珠=次品" |
| 贝母 | 半透，有层状虹彩 | "白色石头" |
| 青金石 | 深蓝带金星与白斑 | "纯蓝" |
| 海蓝宝 | 淡蓝半透，有冰裂 | "清澈透明" |
| 孔雀石 | 带状绿纹，哑光 | "绿色石头" |
| 虎眼石 | 丝绢光泽，随角度变色 | "棕色珠" |
| 木（檀木/黑檀） | 哑光，有毛孔与纹理，会包浆 | "木头色" |

## 结构与工艺可行性分级

- `handmade_simple`：串珠 + 基础五金，10 分钟内可完成，无需焊接。
- `handmade_advanced`：需要绕线、编绳、多股收尾。
- `needs_finding`：依赖特定规格配件（如 12mm 龙虾扣、特定孔径珠）。
- `needs_custom_part`：需要定制件（铸造吊坠、激光切割片）。
- `not_feasible`：结构自相矛盾，不允许交付。

## 常见不可行设计

1. 12mm 以上大珠成串（重、贵、丑）。
2. 吊坠无孔无挂环，靠"贴着"。
3. 耳饰单只 >12g 还用细耳钩（会拉豁耳垂）。
4. 手链只写"链条 + 珠子"却没写链条规格与连接方式。
5. 一个设计里 5 种以上材质（成本与视觉都失控）。
6. 细链（1mm 以下）挂重坠（链先断）。
7. 珠孔 0.8mm 却要求穿 3 股线。
