# 视觉分析维度与转译方法

分析的目的不是描述，是**找到可以落到部件上的东西**。

## 六维观察（只写图里能看见的）

1. **Color** — 用 `color_extract.py` 的实测值，写面积占比与角色，不写"主色调偏蓝"。
2. **Shape** — 几何语言：曲率（直/缓/急）、连续性（连续/破碎）、重复周期、对称性、尖锐度。
3. **Texture** — 表面物理：哑光/镜面/半透/颗粒/纤维/气孔/层理。质感决定材质选择，比颜色更影响成品气质。
4. **Composition** — 视觉重量分布（偏上/偏下/居中）、负空间比例、视线路径、密度梯度。
5. **Style** — 可命名的坐标：极简/繁复、自然/工业、复古/未来、手作/精密。给参照系而不是形容词。
6. **Mood** — 由 L 均值、C 均值、冷暖占比、对比跨度推导（`--mode mood` 已算好），每条情绪词必须挂一个数据依据。

## 象征层（解读，需标注）

象征是推理不是观察，必须写"可解读为"。常见意象：

| 视觉 | 可能象征 | 慎用 |
|---|---|---|
| 潮汐/波浪 | 往复、节奏、情绪起伏 | 不要引到"招财" |
| 贝壳/珍珠 | 包裹、孕育、时间的层积 | — |
| 裂纹 | 修复、侘寂、经历 | 不要接"辟邪" |
| 星轨/月相 | 周期、秩序 | — |
| 年轮/木纹 | 生长、阅历 | — |

## 转译四步法

**特征 → 手法 → 部件 → 材质**

例（海浪照片）：
1. 特征：浪花边缘破碎、不规则、短曲线。
2. 手法：用不对称轮廓取代规则圆/椭圆。
3. 部件：主石外形、包边线条。
4. 材质：巴洛克珍珠（天然不规则）或手工锤纹银片。

例（渐变色水面）：
1. 特征：同一色相从深到浅连续过渡。
2. 手法：同族色按 L 值递增排列。
3. 部件：珠串序列。
4. 材质：同一矿种不同色调（如深/中/浅海蓝宝），而不是换矿种。

例（节奏感潮线）：
1. 特征：疏—密—疏的周期性。
2. 手法：珠距与珠径的变化节奏。
3. 部件：整体结构分段。
4. 材质：大珠段 + 细链段交替。

## 反模式

- 只写形容词（"很美""很有质感"）→ 无法执行。
- 把颜色当唯一信息 → 结构无从下手。
- 把象征当事实（"海洋代表财富"）→ 违规且廉价。
- 一条特征给三个互相冲突的手法 → 选择其中一个并说明取舍。
- 分析完直接跳到成品 → 中间缺"为什么这样转译"。

## 分析输出的最小单元

每条设计机会一行，包含四段：

```
破碎的泡沫边缘 → 用不对称包边代替圆形镶口 → 吊坠外轮廓 → 锤纹 925 银
```

没有这四段的"设计机会"都是空话。
